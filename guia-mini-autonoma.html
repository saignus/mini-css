Instalación

01

Un archivo CSS. Sin fuentes, CDN, paquetes ni compilación. Abre esta guía directamente desde tu computadora.

<link rel="stylesheet" href="mini.css">

Usa el prefijo mn-: componente + color + variante + tamaño.

Ver código HTML
<!doctype html>
<html lang="es">
<head>
<meta charset="utf-8">
<meta name="viewport" content="width=device-width, initial-scale=1">
<link rel="stylesheet" href="mini.css">
<title>Mi proyecto con Mini</title>
</head>
<body><main class="mn-container mn-section">
<h1 class="mn-title">Hola, Mini</h1>
<button class="mn-button mn-primary">Comenzar</button>
</main></body></html>

Tipografía con carácter

03

Fuente del sistema, jerarquía clara y tamaño adaptable. Usa un h1 por página y mantén el orden de los encabezados.

Curiosa por naturaleza.

Ligera por diseño.

Un párrafo con énfasis, un enlace y código inline.

Mucho espacio para respirar, como Mini antes de su próximo salto.
  • Interfaz cálida
  • Ritmo consistente

Botones y estados

04

Combina mn-button con mn-primary, mn-soft, mn-outline, mn-ghost, mn-small, mn-large, mn-rounded o mn-full. Hover, active, foco y disabled están incluidos. Los botones de esta vitrina solo muestran estilos.

Alertas, mensajes y etiquetas

05

El texto y el nombre del estado acompañan al color. Usa role="status" para actualizaciones dinámicas; reserva role="alert" para errores urgentes.

Éxito: Los cambios se guardaron.
Información: La sesión termina en 10 minutos.
Atención: Revisa los datos antes de continuar.
Error: No fue posible guardar. Inténtalo otra vez.

Interacciones ligeras

11

Acordeón y dropdown usan details sin JavaScript. El modal nativo se abre con showModal(): incorpora cierre con Escape, foco inicial y devolución del foco al disparador.

¿Necesito JavaScript para usar Mini CSS?

No para estilos, layout, acordeones y desplegables. El modal y el selector de tema de esta guía usan JavaScript propio de demostración.
